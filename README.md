# SIGR - Documentación de Configuración e Infraestructura

Este repositorio aloja la documentación oficial de Gestión de la Configuración de Software (SCM), esquemas de base de datos y scripts de despliegue para el **Sistema Integral de Gestión de Restaurante (SIGR)**.

## Contenido Incluido:
* `Documento_Linea_Base_SIGR.docx`: Informe de 20 páginas con la especificación técnica de la Línea Base.
* Scripts de automatización y CI/CD.
